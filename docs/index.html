01

Install

两步开始写

01

下载并解压

下载最新 ZIP，解压到一个固定文件夹。压缩包内就是可加载的扩展程序。

下载 md2xarticle.zip ↗
02

加载到浏览器

打开扩展管理页，开启「开发者模式」，点「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。

Chrome chrome://extensions Edge edge://extensions Arc arc://extensions
更新

下载新版并覆盖原文件夹，然后在扩展管理页点一次「重新加载」。

提示

插件尚未上架扩展商店。浏览器启动时可能提示「请停用开发者模式扩展程序」，点忽略或关闭即可。

02

Use

在 X 里导入

  1. 1

    打开文章编辑器

    访问 x.com/compose/articles，手动新建一篇文章，或打开已有草稿。

  2. 2

    点右下角按钮

    看到标题框和正文编辑区后，点击「↑ 导入 Markdown」。

  3. 3

    粘贴或拖入文件

    可以直接粘贴 Markdown，也可以拖入 .md、图片或整个文章文件夹。

  4. 4

    导入到当前编辑器

    点「导入到当前编辑器」，等待进度完成。X 会自动保存。

03

Help

遇到问题

页面右下角没有出现按钮

按钮只会出现在 X 的文章页面。先访问 x.com/compose/articles，进入文章列表或编辑页。

提示找不到文章编辑器

先在 X 里手动新建一篇文章，看到标题框和正文输入区后，再点插件按钮。

某张图片没有插进去

检查图片是否过大或格式异常。插件会重试，重新导入一次通常可以解决。

远程图片下载失败

部分图床有防盗链限制。把图片下载到本地，再和 Markdown 一起拖进面板即可。
